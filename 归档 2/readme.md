我们的核心思想史是首先：
1.对原始文本进行清洗，并将其进行分段
2.在抽取阶段，对于表格类，我们首先会将用户输入的表头和原文的表头进行相似度匹配，之后再抽取对应的行
3.对于非表格类文本，我们是按列匹配和动态主键的方法，首先对于第一列，遍历段落将和第一个表头对照的写入表格
，其次对于后面每一列我们在匹配的时候，会将这个值对应的行的其他已填的表头作为主键，判断该值和表头是否对应，假如不对应，填略，假如只有一个恰好对应，我们会填写，多个的情况下，我们会将这一行整体复制一遍，将值尽可能的都填入到表格中，（在每次对一个值匹配的时候，我们都会遍历一遍所有段落，之后我们会按照表头的格式对段落进行结构化）


注意：文件含有.env,只需要在该环境中启动start.py即可
另外，对于非表格匹配，需要用户选择他属于数值，分类，指标，时间等中的具体哪一个，新手教程中有提到，值回溯点击即可
