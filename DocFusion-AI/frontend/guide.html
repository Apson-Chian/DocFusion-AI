DocFusion

新手使用手册

这是一份面向首次使用者的快速说明。你只需要先定义结果表头，再上传文件，DocFusion 就会按你设定的列名执行解析、抽取和结果展示。

快速上手

  1. 1. 先配置你要的输出列 在首页左侧“提取列配置”中输入列名，比如 项目名称、负责人、联系电话。列顺序就是最终结果表的列顺序。列名确定后，还要为每一列选择合适的槽位，系统会根据槽位决定这一列应当按分类、名称、数值、单位、时间还是同比来处理。
  2. 2. 再上传文件 支持拖拽或点击上传，当前支持 TXT / MD / DOCX / XLSX。多个文件可以一起上传，系统会逐个生成结果卡片。
  3. 3. 等待进度完成 上传后页面会先显示进度卡片。后端完成解析后，页面会自动切换成结果卡片，并显示抽取结果、表格预览和原文片段。
  4. 4. 查看结果和来源 你可以点击结果里的字段值查看来源段落，也可以下载当前任务结果表。每个文件的结果互相独立，不会混在一起。
如果页面刷新后你还想继续看刚才的结果，系统会尝试恢复最近的任务状态。若文件本身处理失败，建议检查表头是否重复，或重新上传一次。

使用建议

  • 表头名称尽量明确，不要重复。重复列名会被系统拦截。
  • 不要把所有列都设成 indicator。表格抽取时，至少要区分分类列和数值列，否则可能出现“解析成功但抽取为空”。
  • Excel 文件建议只保留当前要分析的主要工作表，能提高处理速度和结果可读性。
  • 如果只想抽取几个字段，就只配置那几个列，不要把无关列也加进去。
  • 出现失败时，优先看任务卡片中的错误提示，再决定是否重新上传。

槽位怎么选

槽位不是展示给最终读者看的列名，而是系统内部判断这列“扮演什么角色”的依据。列名可以写成你习惯的中文，槽位则要按这一列的实际含义来选。

  • category：用于表示这条记录属于谁、属于哪一类。常见列名有地区、城市、行业、部门、对象、类别。
  • indicator：用于表示名称、项目名、指标名。常见列名有指标名称、项目名称、职位名称、招录单位。
  • value：用于表示具体数值。常见列名有人数、金额、数量、得分、面积、浓度。
  • unit：用于表示单位。常见内容有人、亿元、%、平方米、件。
  • time：用于表示时间。常见列名有年份、日期、统计时间、月份、时点。
  • yoy：用于表示同比或变化幅度。常见列名有同比、增速、增长率、变化率、涨跌幅。
一个简单判断方法是：如果这一列是在回答“这条记录是谁/属于哪类”，选 category；如果是在回答“统计的是什么名称或项目”，选 indicator；如果是在回答“具体是多少”，选 value。

常见判断规则

什么时候选 indicator？

当这一列本质上是名称、项目名、字段名时，选 indicator。例如 职位名称、项目名称、招录单位、指标名称。

什么时候选 unit？

当这一列专门描述数值使用的单位时，选 unit。例如单元格内容是 人、亿元、%、平方米。

indicator 和 category 容易混淆怎么办？

如果这列更像“记录归属对象”，例如地区、行业、部门类别，优先选 category；如果更像“具体项目名称”，例如职位名称、招录单位、指标项目，优先选 indicator。

value 和 yoy 容易混淆怎么办？

如果这一列表示主数值本身，例如人数、金额、数量，选 value；如果表示增长、下降、变化幅度，选 yoy。

支持的文件类型

  • TXT：适合纯文本公告、报告、访谈记录。
  • MD：适合结构化 Markdown 文档。
  • DOCX：适合正式的 Word 报告、方案、通知。
  • XLSX：适合表格型数据，系统会自动生成表格预览并抽取字段。
以国考职位表为例，推荐这样配置：报考地区 -> category，招录单位 -> indicator，职位名称 -> indicator，招考生人数 -> value。如果把这四列都设成 indicator，就可能导致抽取结果为空。

常见问题

为什么要先填表头？

因为 DocFusion 是按你定义的结果列去抽取信息，不先定义列名，系统无法知道你到底要什么字段。

为什么有时结果为空？

通常是因为文档里没有明确出现对应字段，或者列名定义得太模糊。对于表格文件，还要特别检查槽位是否选对。如果把 地区、人数 这类列都设成 indicator，系统可能会出现“解析成功但抽取为空”。

为什么点击字段值能看来源？

这是为了帮助你核对抽取结果，避免只能看结论、看不到依据。
